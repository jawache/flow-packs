**Kind: Local tool.** flow-packs is a library of guardrail and breadcrumb packs. A project installs it from a git tag as a dev dependency. It runs only inside flow, on its owner's machine: when a commit is made and when an agent session calls a tool. It has no server, no port, no accounts and no published site. Trusted fully: the owner. Half-trusted: an agent session, and the text it reads from the owner's repos, such as staged files, commit messages and env files. Not trusted: anything from outside the machine. What it guards matters most: a rule that stops firing, or a pack that lets a secret into a commit, weakens every repo that binds it.
