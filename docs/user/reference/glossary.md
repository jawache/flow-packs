# Glossary

A pack, an entry, a guardrail, a breadcrumb and a category are flow's words: [flow's glossary](https://github.com/jawache/flow/blob/main/docs/user/reference/glossary.md). A card, a question and a note are work's: [work's glossary](https://github.com/jawache/work/blob/main/docs/user/reference/glossary.md).

## hold

a turn-end guardrail keeps the session's turn open, and its message is the session's next instruction

## line from the web

a line you send to a session from work's web pages: typed into the session with `[web` at its start, and in the issue's `log.jsonl`, an `answer` with `by: line`, or a `note`
